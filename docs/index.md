# EMG/EEG Experiment Program

A Tkinter application for guiding and recording EMG/EEG exercise sessions.

- **Main UI:** `timer.py` → `ExerciseApp`
- **Phase timing & arc:** `core/phase_manager.py` → `PhaseManager`
- **Recording pass-through:** `core/recording_helpers.py` → `RecordingController`
- **UI builders:** `core/ui/*.py`
- **Images & cache:** `util/images.py`, `core/ui/image_loader.py`

Use **Getting Started** to run it. See **Key Actions** for task-based how-tos. Use **API Reference** for full code docs.
