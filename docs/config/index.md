# Configuration Overview

Configuration is intentionally minimal (no external config files). The following are considered "configurable" inputs:

- **Window geometry constants** (see _Constants_)
- **Experiment timings** (entered by the user at runtime)
- **Image paths** (see _Images & Assets_)
- **Hardware selection** (EMG/EEG) at runtime

If you later add a proper config file (e.g., YAML), you can document the keys here and keep legacy defaults for compatibility.
