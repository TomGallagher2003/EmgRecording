# Changing the main experiment UI

The main experiment UI is built in [core/ui/main_screen.py](../api/core/ui/main_screen.md), and images are updated in [timer.py](../api/timer.md), using the "show_image" and "show_next_image" methods. 

To change which images are shown, and how they are updated through the experiment flow, use these files and methods as a starting point.
