    core.recording_helpers¶

    Recording helpers: thin wrapper around a recorder instance.

    This module exposes :class:RecordingController, a pass-through façade that forwards calls to an underlying recorder object. It is designed so that you can add logging, metrics, retries, or safety guards later without changing the UI or the recorder implementation. The class and its methods are documented to be discovered by mkdocstrings for inclusion in your MkDocs site.

    Overview¶

    • Decouples the UI from a specific recorder implementation.
    • Preserves signatures/semantics by delegating directly to self._rec.
    • Provides finish_safe as a guarded variant of finish.

    Integration contract¶

    The wrapped recorder must implement the following methods with compatible semantics (this controller simply forwards to them):

    • make_subject_directory(subject_id, exercise_set=None)
    • set_id(subject_id)
    • finish()
    • receive_and_ignore(duration, no_print=False)
    • get_record(duration)
    • record_initial_rest(rest_time, movement, perform_time)
    • emg_recording(perform_time, rest_time, movement, rep)

    Example¶

    class DummyRecorder: ... def set_id(self, subject_id): pass ... def finish(self): pass ... # ... implement the rest ... ... rec = DummyRecorder() ctl = RecordingController(rec) ctl.set_id("S01") ctl.finish_safe() # won't raise if finish() does

    Notes¶

    • This controller does not perform I/O on its own; it only delegates.
    • Extend this class to layer concerns like logging or telemetry without modifying UI code that depends on the recorder.

    class RecordingController:
    """
    Pass-through wrapper around a recorder instance.

    The controller forwards calls unchanged to the underlying recorder stored in
    ``self._rec``. This allows you to evolve cross-cutting behavior (e.g.,
    retry, logging, timing, tracing) in one place.

    Attributes
    ----------
    _rec :
        The underlying recorder object. It must implement the methods listed in
        the module's *Integration contract* section.
    """

    def __init__(self, recorder):
        """Initialize the controller.

        Args:
            recorder: The concrete recorder to delegate to. It should provide
                the full set of methods expected by the UI (see module docs).
        """
        self._rec = recorder

    # ---- direct pass-throughs (same signatures/semantics) ----
    def make_subject_directory(self, subject_id, exercise_set=None):
        """Create (or ensure) the subject's directory via the recorder.

        Args:
            subject_id: Identifier for the subject (e.g., "S01").
            exercise_set: Optional exercise set or session label.

        Returns:
            Whatever the underlying recorder returns (e.g., a filesystem path
            or a boolean), unchanged.
        """
        return self._rec.make_subject_directory(subject_id, exercise_set=exercise_set)

    def set_id(self, subject_id):
        """Set the current subject ID on the recorder.

        Args:
            subject_id: Identifier to associate with subsequent recordings.

        Returns:
            The recorder's return value, unchanged.
        """
        return self._rec.set_id(subject_id)

    def finish(self):
        """Finish/teardown the recorder session.

        Returns:
            The recorder's return value, unchanged.
        """
        return self._rec.finish()

    def receive_and_ignore(self, duration, no_print=False):
        """Receive samples for a duration but do not persist them.

        This is typically used for device warm-up or to flush buffers.

        Args:
            duration: Time interval to read (in recorder's expected units).
            no_print: If supported, suppress status prints.

        Returns:
            The recorder's return value, unchanged.
        """
        return self._rec.receive_and_ignore(duration, no_print=no_print)

    def get_record(self, duration):
        """Record and return a window of samples.

        Args:
            duration: Time interval to record (in recorder's units).

        Returns:
            The recorder's return value (e.g., sample array/frame), unchanged.
        """
        return self._rec.get_record(duration)

    def record_initial_rest(self, rest_time, movement, perform_time):
        """Record an initial rest period according to the recorder's protocol.

        Args:
            rest_time: Duration of the rest segment.
            movement: Movement label/name to associate.
            perform_time: Duration of the performance segment.

        Returns:
            The recorder's return value, unchanged.
        """
        return self._rec.record_initial_rest(rest_time, movement, perform_time)

    def emg_recording(self, perform_time, rest_time, movement, rep):
        """Run one EMG recording repetition.

        Args:
            perform_time: Duration of the movement performance window.
            rest_time: Duration of the subsequent rest window.
            movement: Movement label/name to associate with this rep.
            rep: Repetition index/count.

        Returns:
            The recorder's return value, unchanged.
        """
        return self._rec.emg_recording(perform_time, rest_time, movement, rep)

    def finish_safe(self):
        """Attempt ``finish()``, swallowing exceptions.

        This utility is intended for shutdown paths where hard failures would be
        disruptive. Any exception message is printed with a simple prefix.

        Side Effects
        ------------
        Prints a diagnostic on exception; otherwise silent.
        """
        try:
            self._rec.finish()
        except Exception as e:
            print(f"[RecordingController.finish_safe] {e}")
